# 科技小院日志 Skill

帮助 AI 找到可取得全文的论文，并据此制作或修改简体中文科技小院文献阅读日志。默认交付标题、封面图片、封面图注和 400—450 字正文；封面为带四周白边的正方形图片。

## 目录

```text
skills/stb-diary/
├── SKILL.md
└── agents/openai.yaml
```

`SKILL.md` 是技能正文，`agents/openai.yaml` 提供 Codex 中显示的名称和示例提示词。使用时将 `skills/stb-diary` 整个文件夹放入 Codex 的技能目录（默认是 `~/.codex/skills/`），然后在请求中写 `$stb-diary`。

## 使用方法

1. 直接说“来一篇科技小院日志”，技能会找一篇可取得全文的论文，核实后写成文献阅读日志；也可以指定主题或论文。
2. 需要保存成品时指定位置；未指定位置时，技能可以先在对话中交付文字，并在保存文件前询问位置。
3. AI 核对来源后，交付标题、封面图片、封面图注和 400—450 字正文。文献日志还会在指定位置保存可取得的论文全文和实际使用的阅读材料。

### 让 AI 找论文后直接写

> 请使用 $stb-diary，来一篇科技小院日志。

如需限定方向和保存位置，也可以这样说：

> 请使用 $stb-diary，帮我找一篇与土壤盐渍化相关、能取得全文的中文论文。核实题录和原文后，选一个具体段落写科技小院文献阅读日志，并制作相关封面。请把日志、论文 PDF 和实际使用的截图保存到我指定的文件夹：……

### 使用自己提供的论文

> 请使用 $stb-diary，根据我提供的论文和阅读记录写一篇科技小院日志。封面使用论文中的图 2，按技能要求补成带白边的正方形。请将成品保存到我指定的文件夹：……

只说“写今天的日志”而未提供论文时，同样默认找论文写文献阅读日志。找不到可核实的论文全文或相关封面时，应说明限制，不把摘要、错误页或无关图片当作已取得的材料，也不声称使用者已经读完整篇论文。

## 使用边界

- 400—450 字、四个栏目和封面白边是本技能的默认交付规格，不代表各单位的统一标准；使用者或其单位明确指定其他规格时，以其要求为准。
- 保存位置由使用者指定。没有指定位置时，可以先在对话中提供文字草稿；需要生成或下载文件时再询问位置。
- 新作文献日志时，在指定位置一并保存核实后的论文全文、日志、封面和实际使用的截图，并在日志中记录题录、页码、图号与图片来源。
- 仓库只包含技能说明，不包含论文全文、用户日志或个人工作资料。
- 文献的题录、结论与配图来源需核实；能访问摘要不代表已取得全文。

本仓库尚未选择开源许可证。若要允许他人明确地复制、修改或再分发，请在发布前选定并加入合适的许可证。
